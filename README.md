# Maré Boa: dados

Robôs que montam os dados de previsão usados pelo app Maré Boa: modelos de vento, ondas e água (GFS, ECMWF, Open-Meteo),
marégrafos da EPAGRI/CIRAM, tábuas de maré, rios do litoral (OpenStreetMap) e o aprendizado semanal com as pescarias.

- `main`: os robôs (`tools/`) e os horários (`.github/workflows/`).
- `dados`: os arquivos gerados, publicados em https://hericsaliby.github.io/mare-boa-dados/

Nenhum ponto de pesca de usuário passa por aqui.
